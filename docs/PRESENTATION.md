# SCIP – Project Presentation Slide Outline (PPT)

---

## Slide 1: Title Slide
- **Title**: SCIP – Smart Cybersecurity Intelligence Platform
- **Tagline**: AI-Powered Security Knowledge & Incident Management System
- **Presenter**: MCA Final-Year Project Presentation

---

## Slide 2: Problem Statement
- SOC teams are overwhelmed by incident volume.
- Security documentation & SOPs are scattered across repositories.
- Traditional search lacks context and threat containment guidance.

---

## Slide 3: Proposed Solution
- Centralized Incident Response Hub.
- RAG-powered AI Security Copilot utilizing Google Gemini & PostgreSQL pgvector.
- Role-based security (Admin, Analyst, Employee).

---

## Slide 4: System Architecture
- **Frontend**: React + TypeScript + Tailwind CSS.
- **Backend**: ASP.NET Core 8 Web API (Clean Architecture).
- **Database**: PostgreSQL 16 + pgvector HNSW index.
- **AI Service**: RAG pipeline with document chunking.

---

## Slide 5: Core Features & Demonstration
- Live Security Telemetry Dashboard.
- Incident creation, severity assignment, and status updates.
- AI Copilot with RAG source citations & investigation checklists.
- PDF/CSV Executive Analytics exports.

---

## Slide 6: Conclusion & Future Scope
- Enterprise-ready monorepo platform.
- Future Scope: Multi-tenant SIEM integration, automated SOAR playbooks.
