# SCIP - User Manual & Operator Guide

Welcome to the **Smart Cybersecurity Intelligence Platform (SCIP)**. This user manual explains how to use all features of the SCIP web interface and AI Security Copilot.

---

## 1. Authentication & Role Selection

SCIP enforces Role-Based Access Control (RBAC) across three distinct user roles:

| Role | Access Scope | Primary Functions |
| --- | --- | --- |
| **Admin** | Full System Control | Manage users, roles, system parameters, and global analytics |
| **Analyst** | SOC Operations | Investigate incidents, update status, upload RAG docs, consult AI Copilot |
| **Employee** | Basic Portal | Report incidents, query company security policy via AI Copilot |

### Logging In:
1. Open `http://localhost:3000/`.
2. Select your desired demo role (**Admin**, **Analyst**, or **Employee**).
3. Click **Authenticate & Access SCIP**.

---

## 2. Cyber Threat Intelligence Command Dashboard

The Dashboard provides high-level situational awareness:
- **Live Security Metrics**: Open incidents count, MTTR performance, indexed RAG documents, and total AI Copilot queries.
- **Active Security Incidents**: Real-time list of reported threats sorted by severity (`Critical`, `High`, `Medium`, `Low`).
- **Suggested AI Tasks**: Real-time threat recommendations generated by the RAG engine.

---

## 3. Incident Operations Hub

Use the Incident Operations Hub to manage security events from triage to remediation:

### Reporting a New Incident:
1. Click the **Report New Incident** button in the top right.
2. Enter the incident title, severity, category, and detailed evidence notes.
3. Click **Submit Incident Report**.

### Investigating an Incident:
1. Click any incident card in the left list to view details.
2. Update status using the status dropdown (**New** → **Investigating** → **In Progress** → **Resolved** → **Closed**).
3. Post investigation notes or IOC hashes in the timeline comment section.

---

## 4. AI Security Copilot ⭐ (Hero Feature)

The AI Copilot uses Retrieval-Augmented Generation (RAG) over indexed security policies and NIST frameworks:

### Asking Questions:
1. Click **AI Security Copilot** in the navigation sidebar.
2. Type your question in the query input bar or click one of the suggested question chips (e.g., *"How do I isolate an endpoint infected with ransomware?"*).
3. Click **Ask AI**.

### Features:
- **RAG Source Citations**: Review the exact documents retrieved from pgvector (e.g., *NIST SP 800-61 Rev 2*).
- **Copy Response**: Click **Copy** to copy formatted security procedures.
- **Reset Chat**: Click **Reset Chat** to start a new investigation context.

---

## 5. Knowledge Base & Vector Indexing

The Knowledge Base houses all indexed cybersecurity documents:
- **Uploading Files**: Click **Upload Document to RAG Vector DB**, select category (**Frameworks**, **Threat Intel**, **SOP**, **Advisories**), enter tags, and upload.
- **RAG Embeddings**: Uploaded documents are automatically chunked into 500-word segments and embedded into PostgreSQL `pgvector`.

---

## 6. Reports & Analytics

- View monthly incident category distribution and RAG query breakdown.
- Export executive summaries via **Export PDF** or **Export CSV**.
